# Lab 4 Notes

In Part 4, deleting the "Library and Information Science" department gave Error 1451: "Cannot delete or update a parent row: a foreign key constraint fails." MySQL refuses because the Student table has a foreign key (`dept_id`) pointing to that department, and the student "Transfer Student" still belonged to it. Deleting the department would leave that student pointing at a department that no longer exists, which breaks referential integrity. I fixed it by first updating the student's `dept_id` to Software Engineering, then deleting the department, so the student was moved instead of lost. Another fix would be to define the foreign key with `ON DELETE CASCADE`, which deletes the dependent students automatically, or `ON DELETE SET NULL`, which keeps the student but clears their department (the column must allow NULL). I chose reassigning because it keeps the student's data and makes the change deliberate.
